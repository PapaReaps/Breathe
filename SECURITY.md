# Security policy

Breathe Money keeps your numbers on your own device and never sends them anywhere. If you find a way that could put someone's numbers or phone at risk, thank you for telling us. Please tell us **privately**, so it can be fixed before anyone else hears about it.

## Which versions get fixes

Only the **newest version** gets safety fixes. If you're on an older one, please update first:

- **Android app:** **Menu → Settings → App options → Updates → Check now**, then **Download and install**. Or download the newest `.apk` from the [Releases page](https://github.com/PapaReaps/Breathe/releases/latest).
- **Website** ([papareaps.github.io/Breathe](https://papareaps.github.io/Breathe/)): it updates by itself.

## How to tell us privately

1. Go to this project's **[Security tab](https://github.com/PapaReaps/Breathe/security)**.
2. Click **Report a vulnerability**, and describe what you found and how to see it happen.
3. Only the person who looks after Breathe can read it.

Please **don't** use the public "Report a problem" page for safety problems, because everyone can see those.

**Please never include real numbers, passwords, PINs or backup passphrases.** Made-up examples are perfect.

## What happens next

Breathe is a free, personal project looked after by one person, so please be patient.

- We aim to reply **within 7 days**, to say we've seen it.
- If it's a real problem, we'll fix it as soon as we can, put out a new version, and say what was fixed in the release notes. We'll thank you there too, if you'd like.
- If it turns out not to be a safety problem, we'll explain why, kindly.

## What counts

Things like:

- someone else being able to see or change your numbers, PIN or backups,
- a backup file being opened without its passphrase,
- the Android app being tricked into installing something that isn't Breathe Money,
- the app sending anything off your device that it says it doesn't.

What we already know and say openly (see [PRIVACY.md](PRIVACY.md)): numbers saved in the browser aren't encrypted, and the PIN is a privacy screen, not encryption.

Thank you for helping keep Breathe safe for everyone.
