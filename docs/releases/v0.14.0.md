**Updates that download and install from inside the app.**

## What's new

- **Download and install (Android app).** In **Menu → Settings → App options → Updates**, tap **Check now**. When a new version is out, tap **Download and install**. The app downloads it, then Android asks **"Do you want to update this app?"**. Tap **Update**, and your numbers stay.
- **The first time,** Android asks for your OK: tap **Open the setting**, switch on **Allow from this source**, come back and tap **Install now**. You only do this once.
- **Kept safe.** The app only downloads from Breathe Money's own GitHub releases, checks the file really is Breathe Money, and Android refuses any update that isn't signed with the same key. Your numbers are never sent.
- **New front-page pictures** showing "money coming in" and Savings.

## Updating to this version

- **Android:** download `breathe-money-v0.14.0.apk` below and install it over the old one, one last time by hand. Your numbers stay. After this, new versions can download and install from inside the app.
- **Web link:** [papareaps.github.io/Breathe](https://papareaps.github.io/Breathe/) updates by itself, as always.

Breathe Money is an organisation tool, not financial advice.
