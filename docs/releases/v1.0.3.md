**Getting ready for the next Breathe app.**

## What's new

- **Update checks only look for Breathe Money.** Breathe Medication is on the way, and its releases will sit on the same GitHub page. Breathe Money now checks for its own updates by name, so it never gets confused by another Breathe app. Nothing else about the check has changed: it's still off unless you switch it on, and nothing about you or your numbers is sent.
- **Obtainium:** the **Add to Obtainium** link in the README now only ever picks Breathe Money's download. If you added Breathe Money to Obtainium by pasting the address, the README explains the one setting to change.

## Updating to this version

- **Android:** you'll see an **Update ready** pop-up, or go to **Menu → Settings → Updates**, tap **Check now**, then **Download and install**. Your numbers stay.
- **Android (older versions, or a first install):** on your phone, tap [this download link](https://github.com/PapaReaps/Breathe/releases/latest/download/breathe-money.apk), then open it. [How to install it](https://github.com/PapaReaps/Breathe/blob/main/docs/ANDROID-APP.md).
- **Web link and computer app:** [papareaps.github.io/Breathe](https://papareaps.github.io/Breathe/) updates by itself.

Breathe Money is an organisation tool, not financial advice.
