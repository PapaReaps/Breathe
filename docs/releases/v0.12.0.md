**Know when there's a new version.**

## What's new

- **Check for updates (Android app).** Go to **Menu → Settings → Updates**. Tap **Check now**, or switch on **Check once a day when I open the app**. When a new version is out, you'll see a small note with a link to get it.
- **It's off until you switch it on.** Checking asks GitHub one question, "what's the newest version?". Your numbers are never sent. GitHub can see that a phone asked, as with visiting any website.

## Updating to this version

- **Android:** download `breathe-money-v0.12.0.apk` below and install it over the old one. Your numbers stay. From now on, the app can tell you about new versions.
- **Web link:** [papareaps.github.io/Breathe](https://papareaps.github.io/Breathe/) updates by itself, as always.

Breathe Money is an organisation tool, not financial advice.
