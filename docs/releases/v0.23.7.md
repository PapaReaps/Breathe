**Updates show straight away on computers.**

## What's new

- If you use Breathe Money on a computer (or added it to your home screen from the web), it now checks for a newer version every time you open it. Before, the browser could keep showing the previous version for up to 10 minutes after an update.
- It still opens with no internet, using the copy it saved last time.

If your computer still shows an older screen, click into the Breathe window and press **Ctrl + Shift + R** once.

## Updating to this version

- **Android (from v0.14.0):** go to **Menu → Settings → App options → Updates**, tap **Check now**, then **Download and install**. Your numbers stay.
- **Android (older versions, or a first install):** on your phone, tap [this download link](https://github.com/PapaReaps/Breathe/releases/latest/download/breathe-money.apk), then open it. [How to install it](https://github.com/PapaReaps/Breathe/blob/main/docs/ANDROID-APP.md).
- **Web link and computer app:** [papareaps.github.io/Breathe](https://papareaps.github.io/Breathe/) updates by itself, now straight away.

Breathe Money is an organisation tool, not financial advice.
