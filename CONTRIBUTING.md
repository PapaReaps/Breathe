# Contributing to Breathe

Thank you for wanting to help. Breathe is a calm, kind project, and we would like contributing to feel the same.

## The founding promise

> **Breathe will never be about making money. It will always be about helping people.**

Before suggesting or making any change, ask:

1. Does this help people?
2. Does it reduce stress rather than add to it?
3. Does it protect privacy?
4. Could someone with ADHD use it on a tired, overwhelmed day?

If the honest answer to any of these is "no", we will not do it.

## Rules everyone follows

**Privacy**
- No tracking, analytics, adverts or third-party scripts.
- No accounts, and no collection of personal information.
- No real personal or financial data in code, tests, screenshots or issues. Use fictional examples.
- Never ask for bank login details.

**Wording and design**
- No shame or guilt language, no streaks, no countdown pressure.
- No financial jargon. If a plain word exists, use it.
- Keep notifications to a minimum, and always optional.
- All wording lives in the `content` folder so tone can be reviewed in one place.

**Code**
- Avoid new dependencies. Any new one needs a written reason: what it does, who maintains it, and why we cannot do without it.
- Changes to money calculations **must come with tests**.
- Keep calculation code separate from screen code.
- Money is stored as whole pennies, never as decimals.
- Keep changes small, and explain them in plain English.

**Money**
- Essential features stay free and work without any connection to a bank.
