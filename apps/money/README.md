# Breathe Money

**Status: Stage 1 (Hello Breathe).** A tiny starter page and one example test. No money features yet.

## Run it (Windows PowerShell, inside this folder)

```
npm install        # downloads the tools (first time only)
npm run dev        # starts the app: open http://localhost:5173
npm test           # runs the automatic checks
```

Stop the app with `Ctrl+C`.

## Folders

| Folder | Purpose |
|---|---|
| `src/` | The app itself |
| `src/content/` | All the words people see |
| `tests/` | Automatic checks |

More folders (`screens`, `components`, `logic`, `storage`) are added when they are first needed, rather than being created empty.
